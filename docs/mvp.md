# MVP (Minimum Viable Product)

> Original MVP scope, retained as a historical record. M9 now implements seven assessment-document templates and PDF downloads; general teaching tools remain planned. See [final handover](final-handover.md).

## Goal

Create a working platform where teachers can create questions and students can solve them.

## Version 1 Features

### Authentication

- Login
- Registration
- User roles

### Teacher

- Create question
- Edit question
- Delete question
- View question bank

### Student

- Solve questions
- Receive score
- View progress

### System

- Save users
- Save questions
- Save results

## Out of Scope

The following features will be implemented later:

- Exam builder
- Automatic question generation
- LaTeX automation
- Course management
- Visualizations
- AI features
