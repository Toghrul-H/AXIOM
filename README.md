# Interactive Teaching and Learning Support Platform for Discrete Mathematics I

## Overview

The Interactive Teaching and Learning Support Platform for Discrete Mathematics I is a web-based system designed to support students, demonstrators, and instructors involved in the Discrete Mathematics I course.

The platform aims to improve the learning experience of students while also simplifying course administration, exercise management, assessment preparation, and educational content generation for teaching staff.

## Objectives

* Support student learning through interactive educational tools.
* Support demonstrators in preparing and managing exercises.
* Support instructors in course administration and assessment preparation.
* Reduce repetitive manual work through automation.
* Provide a centralized platform for educational and administrative activities.

## Planned Features

### Student Features

* Learning materials
* Practice quizzes
* Exam simulation
* Progress tracking
* Interactive visualizations

### Demonstrator Features

* Question bank access
* Practice sheet generation
* Exercise management

### Instructor Features

* Question bank management
* Exam builder
* Automatic question generation
* Automatic solution generation
* Assessment management
* Course information management
* LaTeX document automation
