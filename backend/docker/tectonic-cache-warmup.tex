\textbf{AXIOM Practice Sheet mathematical font warm-up}

The default 10pt size deliberately warms the 7pt script fonts used by ordinary
expressions such as $x^2+y^2=z^2$. Display, text, script, and scriptscript
styles exercise the remaining Computer Modern reduced-size PDF fonts:
\[
  \displaystyle \sum_{i=1}^{n}\frac{x_i^2+y_i^2}{z_i^2}
  \quad \textstyle x^2+y^2=z^2
  \quad \scriptstyle a_i^2+b_i^2=c_i^2
  \quad \scriptscriptstyle p_{ij}^{kl}+q_{ij}^{kl}=r_{ij}^{kl}.
\]
Prove that $A \cap B = B \cap A$ and show that
$\lvert A \cap B\rvert \le \lvert A\rvert$.

{\fontsize{11}{13}\selectfont
The 11pt Practice Sheet size also uses
$\displaystyle \sum_{i=1}^{n}\frac{x_i^2}{z_i^2}$.
